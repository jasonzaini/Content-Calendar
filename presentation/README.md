# Agency management presentation

The deck contains 33 slides: 23 core slides for a 15–20 minute management presentation, plus 10 appendix slides. It includes 26 screenshots of the working prototype and speaker notes on every slide. Headings and annotations are editable; screenshots are images.

## Download

1. Click **Content-Studio-Management-Case.pptx** in this folder.
2. On the file page, click the **Download raw file** button (downward arrow) at the top right of the file panel. If GitHub cannot preview the PowerPoint, use that download button anyway.
3. Open the downloaded file in Microsoft PowerPoint. Presenter View shows the speaker notes.
4. For the handout, open **Content-Studio-Management-Case.pdf** and use the same download button.

Files:

- [PowerPoint deck](Content-Studio-Management-Case.pptx)
- [PDF handout](Content-Studio-Management-Case.pdf)

The PDF is a visual handout generated from the same slide composition, rather than a PowerPoint-rendered export. Minor font wrapping can differ in PowerPoint.

The presentation uses fictional demo content. Planning and caption examples are deterministic, asset matching uses filename rules, and the savings calculator is illustrative. The portable HTML role selector simulates access and is not production authentication. Production release gates are described in the deck.
